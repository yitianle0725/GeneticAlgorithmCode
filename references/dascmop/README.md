# DAS-CMOP reference fronts

这些 `.pf` 文件来自 pymoo 官方数据仓库：

<https://github.com/anyoptimization/pymoo-data/tree/main/pymoo/pf/DASCMOP>

原始文件名为 `dascmop<problem>_<difficulty>.pf`。本项目增加 `d` 前缀，保存为
`dascmop<problem>_d<difficulty>.pf`，以便与实验问题 ID 完全一致。

上游仓库使用 Apache-2.0 License。这里只收录冻结的 DASCMOP7–9、难度
4/8/12/16 所需参考前沿，保证实验离线可复现。
